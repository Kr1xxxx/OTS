# OTS 新版界面原型

交互原型，单个 HTML 文件，直接用浏览器打开即可。数据全部是虚构示例，不读写真实数据库，也没有改动 `trade-order-system.html`。

| 文件 | 内容 |
| --- | --- |
| `ots-ui.html` | 桌面版主原型（1440 × 920 pt 窗口），新建弹窗是方案 D |
| `ots-modal-a.html` | 新建弹窗方案 A：单栏 |
| `ots-modal-b.html` | 新建弹窗方案 B：左侧粘贴驱动 |
| `ots-modal-c.html` | 新建弹窗方案 C：紧凑标签在左 |

A / B / C 打开后会自动弹出新建订单弹窗，其余部分和主原型一样。弹窗方案还没有定。

原型里还有这些新功能：顶栏铃铛打开的通知面板；独立的订阅页（数据只在这一页）；看板卡片右键菜单里按住删除，取代原来的回收站列。

已对照 V3.88 补齐审查清单里的 P0 和 P1。下面这些原版没有，原型里也已经去掉：飞书和 WhatsApp 设置页、逐笔收款记录、欧洲央行汇率（改为按月手填 USD → RMB）。

「AI 识别」按钮在 claude.ai 的 Artifact 里才会真的调用模型；本地打开时会自动退回本地规则识别。

设计规范见 Kr1xxxx/skills 仓库里的 `ots-ui-spec` skill（Arc + Evil Buttons）。
